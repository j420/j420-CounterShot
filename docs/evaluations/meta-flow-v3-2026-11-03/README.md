# Live Meta v3 evaluation archive

This is an unchanged copy of the six-response synthetic challenge run from 3 November 2026. Original temporary paths inside raw records remain as provenance. Each case directory includes the copied source images, input, result, model traces and execution records.

`summary.json` records six passes, six known responses and no retries. Controller replay records are separate files; they never modify paid results or start inference. Replay resolves copied images relative to this archive.

These are new rendered diagrams, not photographs or physical trials. The scoring expectations were withheld from model input. This fixed challenge set is not an independent physical benchmark. The live run covered ordinary v3 reasoning; the owned historical retrieval/finalization path was tested with mocked SDK responses separately.
