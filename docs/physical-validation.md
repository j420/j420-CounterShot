# Physical admission — custom workshop jigs

The current fixture library is experimental. Geometry checks and complete model responses do not demonstrate holding, alignment or independent assembly. Follow the [flagship build brief](workshop-build-brief.md) for the exact part family and bill of materials.

## Establish the real operation

Record a compatible supplied six-panel set and the actual base-first joining sequence. Capture the original holding/alignment conflict; if the one-hand baseline is blocked, label any helper demonstration of the remaining operations separately. Do not demand an impossible original attempt.

Confirm actual workpiece/panel dimensions, joining travel and measured access windows on all four edges. State operator capabilities, maximum completed-object lift, reach and permitted supports. Confirm actual fixture material/coupon and the alignment tolerance/inspection method. Missing facts must not become model guesses.

## First admission: transfer the holding duty

At every panel locate-to-join boundary, release the hand and perform its actual next motion. Inspect inward/outward tipping, loss of datum, brace flex/slip, workpiece bowing and access to both sides of the joint. A declared exterior brace is an intended support, not proof that it carries the required load or direction.

If the actual part set already stays aligned without a jig, record that result and compare with the simplest adequate aid. If the kit cannot use the supported joint order or requires unsupported force/cure/powered operations, do not promote it as admitted.

## Build and full-cycle test

Construct the exact revision and verify the 50 mm scale square. Record maker help, connectors, material/geometry corrections and substituted stock. Corrections outside the checked design require a new revision.

Test loose-base loading with gate initially parked; all wall locations/joins; lid insertion; completed-joint retention; gate disengagement and parking; front extraction within the stated lift; finished-output placement; and clear next-stock access/reset. Actual movement paths and tape renewal belong in the test, including any intervention.

Select the exact build and upload separate uninterrupted MP4 trial footage. A human reviews registration, alignment, completion, release, reset and allowed resources. Record actual maximum alignment error using the predeclared method. A value above the built revision's tolerance fails alignment; missing measurement/video/readiness remains incomplete. Synthetic projects cannot produce physical completion records.

All attempts and failures remain in the evidence log. The software binds a person's assessment to its exact records; it cannot independently establish that a clip depicts the claimed physical build.

## Revision and comparison

Feed a genuine failure plus measured evidence to a new revision job. Inspect which support, access feature or operation dependency changes. Build and test the revised exact output. Do not silently trim a rail or add a helper clamp to make an AI output appear successful.

Compare against sensible corner blocks/squares/clamps and an equally informed direct assistant with the same tools and budget. Include construction/setup costs separately from repeated operation. Freeze the supported part/joint/material envelope, prompts, code, grammar, success definition and iteration budget before a held-out adaptation. A larger fixture alone is resizing evidence; claim structural adaptation only when changed geometry, support duties and action dependencies are actually demonstrated.

There is no established force rating, broad reliability, ergonomic, clinical or manufacturing-accuracy claim from this prototype. The physical result determines the public claim.
