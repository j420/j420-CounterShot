# Flagship build brief: temporary support, access and release

The selected best candidate is a **custom workholding jig for assembling a small flat-pack instrument enclosure**. The useful conflict is simultaneous: loose walls must remain located/upright while the available hand seats another joint. The fixture must preserve joint access and let the completed object leave intact.

The six supplied parts are base, left wall, right wall, rear wall, front wall and lid. CounterShot keeps their design fixed. Start with one exact low-force, hand-insertable joint family that genuinely permits base-first, wall-by-wall assembly and a final lid. The completed joints must retain the assembly before fixture support is removed. A part set that does not meet those conditions is outside this first grammar.

## Concrete first build

Use an existing compatible pre-cut panel kit or parts prepared by a maker from an existing workpiece drawing. The app's reference dimensions are synthetic examples, not purchasing or fabrication specifications. Confirm the actual kit by an unconstrained reference assembly before evaluating a one-hand operating condition.

Materials and equipment to prepare:

- One exact six-panel part set plus a repeatable loose-part supply layout.
- Actual measured cardboard/chipboard sheet for the proposed jig. A stiffer material is a new profile/revision, not an undocumented substitution.
- Ruler, square, cutting/scoring tools, cutting mat and declared tape/connectors. The maker can prepare the jig; record this help separately from operation.
- A material-specific fold/fit coupon, an actual-size print with a measured 50 mm scale square, and adequate sheet size for every blank.
- A stable tabletop, a marked front-left origin and the operator-confirmed reach region.
- A phone/camera view that shows hand releases, panel alignment, joint seating, gate parking, extraction and reset. A second still angle may help inspection; it does not replace uninterrupted cycle evidence.

The proposed fixture uses a base plate, split exterior braces and a removable front gate. Gate notches and separated braces leave measured joint windows accessible. Each fixed brace takes an explicit unfinished-wall support duty. The gate starts parked so the fresh base can enter, engages before the front wall needs support, then releases only after complete self-retaining joints.

## Measurements and facts

Measure/confirm:

1. Actual workpiece outer width/depth/height from the supplied parts or their authoritative drawing; actual panel thickness.
2. Joining travel and exact edge access rectangles: edge, along-edge start/end, and lower/upper height. Confirm every edge; missing rectangles are unknown access, not proof of clearance.
3. Operator-permitted manipulations, body supports, reach, front extraction direction and allowable completed-object lift.
4. Jig board thickness, usable sheet size, material-specific score/fold correction and fit coupon.
5. Required alignment tolerance and inspection method. Measure the maximum error at the named reference edges with the chosen ruler/square method; do not invent precision.
6. Whether the completed joints self-retain, established on the actual supplied family. This still needs confirmation during the evaluated cycle.

The model may choose fixture offsets, brace placement/length/height, gate geometry and reliefs within the supported grammar. It cannot invent these measured workpiece/material facts, change the product's joints, relax the tolerance or add a second hand.

## Admission order

**First test: support transfer.** At every locate-to-join boundary, release the hand and perform the actual next hand movement. Observe inward tipping, loss of datum, brace flex/slip and inaccessible joint faces. Merely naming a brace is insufficient.

Then test:

- Fresh loose base entry with gate parked; no hidden helper preload.
- Each wall location and join using the actual allowed hand/actions while previous walls remain supported.
- Lid position/join with all required walls in place.
- Gate disengagement and parking without creating a new holding conflict.
- Complete front extraction within the allowed lift, finished-output placement, and an empty jig with clear next-part pickups.
- Actual alignment and completed-joint retention after fixture removal.

If a joint requires another insertion direction, high force, curing, powered work or a different assembly topology, record unsupported rather than pretending the current representation validates it. Operator stop is always allowed.

## Evidence and comparison

Record every attempt against the exact build. Review registration, alignment, completion, release, reset and allowed resources. Record actual maximum alignment error and distinguish incomplete footage from an actual failure. Maker construction and operating assistance remain separate.

The practical baseline is sensible corner blocks/squares and ordinary clamps with equivalent supplies. If that complete method is simpler and equally effective, report it. Include initial setup/construction, corrections and repeated operating effort separately.

A strong revision responds to a genuine obstruction or loss of support: relocate/split a fence, add a measurable gate relief, and change the relevant joining or release dependencies. An independently chosen held-out part/constraint combination must remain within a physically admitted family and frozen evaluation budget. The software's synthetic tests demonstrate checking behavior; only physical results can establish a capability or comparative advantage.
